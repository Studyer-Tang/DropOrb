# DropOrb

> Drop anything. Get the right action.

DropOrb 是一个零配置、仅在本机运行的 Windows 桌面投递球。把图片、ZIP、文件夹、PDF、普通文件、文字或链接拖到小球上，或直接处理剪贴板，它会识别内容并给出最合适的操作。

## 懒人入口

- 文件拖进小球后展开环形投递：上方推荐、左侧暂存、右侧复制桌面、下方更多
- `Ctrl + Alt + D`：在任何软件中直接处理当前剪贴板
- `Ctrl + Alt + Space`：打开快捷命令，输入关键词后回车执行
- 鼠标中键单击投递球：处理剪贴板
- 可在右键菜单按需开启“文件管理器发送到”，之后选中文件即可从 Windows 的“发送到”菜单交给 DropOrb
- 右键投递球或托盘图标：打开下载目录、新建桌面便签
- 右键投递球或托盘图标选择“功能说明”：在软件内查看完整用法
- 可在右键菜单中选择开机自动启动
- 复制截图后按快捷键，会自动保存到本地收件箱并按图片处理

## 越用越顺手

- 每种内容分别记录动作使用次数，常用动作会逐渐排到前面
- 学习只改变排序，不会未经允许自动执行
- 耗时的复制、压缩和图片转换在后台运行，悬浮球外圈显示工作状态
- “任务与撤销”中心可以查看任务、定位输出，并撤销 DropOrb 新生成的内容
- 右键菜单可以随时重置动作偏好

## 当前功能

### 图片

- 置顶预览，可拖动，双击关闭
- PNG/JPG 格式转换
- 生成压缩 JPG 副本
- 生成尺寸减半的副本
- 复制图片到剪贴板
- 在资源管理器中定位

### ZIP 压缩包

- 防路径穿越的安全解压
- 解压到新的同名目录并打开
- 预览压缩包内容
- 复制到桌面
- 计算 SHA-256 校验值
- 加入临时架

### 文件夹

- 打包为 ZIP
- 生成 TXT 目录树
- 复制第一层文件名
- 复制完整路径
- 复制整个文件夹到桌面
- 加入临时架

### 文字和链接

- 复制纯文本
- 整理为单行文字
- 从长文本中提取所有链接
- 使用默认浏览器打开链接
- 清理链接中的常见跟踪参数
- 保存桌面 TXT 或 `.url` 快捷方式
- 文本字数统计
- 加入临时架

### 通用文件和 PDF

- 打开
- 复制到桌面
- 打包为 ZIP
- 计算并复制 SHA-256
- 打开所在位置
- 加入临时架

### 多文件

- 把文件和文件夹打包为一个 ZIP
- 复制全部名称或完整路径
- 全部复制到桌面并自动避开重名
- 一次加入临时架

## 使用方式

- 直接拖入：展开环形快速投递；拖到下方或中心可查看最多六个动作
- `Shift + 拖入`：立即执行第一项推荐操作
- `Ctrl + 拖入`：直接加入临时架
- 单击投递球：打开临时架
- 拖动投递球：移动并自动吸附屏幕边缘
- 右键投递球：查看任务与撤销、重置偏好、隐藏或退出
- 双击托盘图标：重新显示投递球
- 已启动时再次运行 `DropOrb.exe 文件路径`，文件会转交给现有窗口，不会重复启动程序

所有转换、压缩和目录树操作都会创建新文件，不会覆盖原文件。临时架只记录路径或文字，不移动原文件。

## 代码结构

- `ActionEngine`：只负责按内容类型提供动作
- `PreferenceStore`：持久化动作使用频率并进行稳定排序
- `JobManager`：串联后台任务状态、完成通知和输出结果
- `UndoStore`：只记录 DropOrb 明确生成的路径，并在撤销前再次确认
- `SingleInstanceBridge`：负责把资源管理器传入的文件转交给已运行实例
- `SendToIntegration`：只负责安装或移除 Windows“发送到”快捷方式
- `QuickCommandForm`：提供可搜索的常用命令入口，不承载文件处理逻辑
- WinForms 窗口各自只负责展示和用户交互，不复制文件处理逻辑

## 运行

双击：

```text
DropOrb.exe
```

要求 Windows 10/11，无需管理员权限。

## 从源码构建

退出正在运行的 DropOrb，然后双击：

```text
build.cmd
```

构建使用 Windows PowerShell 5.1 自带的 C# 编译能力，不隐藏窗口、不绕过执行策略，也不需要 Visual Studio。

## 本地数据

临时架和悬浮球位置保存在：

```text
%LOCALAPPDATA%\DropOrb
```

DropOrb 不上传文件、文字、历史记录或使用数据。
